# DelugeMidi

The original project became obsolete due to the [midi follow mode](https://delugecommunity.com/features/midi_follow_mode/) provided by the community firmware.

In this repo, you can now find a primitive [editor](https://cgoehl.github.io/deluge-midi) to generate the config file (`SETTINGS/MIDIFollow.XML`) to match to the default LaunchControl XL CC layout.
